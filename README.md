# Discovery Copilot

A small demo of how I approach forward-deployed AI work: turn messy stakeholder conversations into the *real* problem, a process map, AI opportunities, and a baseline and success measure — before building anything.

**Live demo:** https://ronan1111341.github.io/discovery-copilot/

- **Sample mode:** three fictional real-estate scenarios (lease admin, arrears, contract review). No key needed.
- **Live mode:** paste your own Anthropic API key to run Claude on your own notes. The key stays in your browser and is sent only to api.anthropic.com. Don't paste real client data.

Single static `index.html`, no build step.
