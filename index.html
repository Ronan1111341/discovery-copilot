About this show site

Foyer is a design concept for an AI workspace for real estate agents. It is a show site: every animation is scripted on invented sample data. Nothing is read, searched, saved or sent, and no real client or property appears.

The email demo shows the idea. An enquiry arrives, the assistant finds the earlier conversation, updates the client file and drafts a reply for the agent to approve.

Built as a portfolio piece by Ronan1111341. Source on GitHub · Earlier prototype: Discovery Copilot (analyses interview notes with Claude, using your own API key).
